### Cross-cutting

- **`commander` is not a dependency** but is imported by `scripts/github-actions/progressive-backfill.js`, `recover-stuck-chunks.js`, `report-failure.js`, and `capture-pr-details-graphql.js`. The Progressive Repository Backfill and Chunk Recovery workflows have failed on `ERR_MODULE_NOT_FOUND` since early 2026 and GitHub has disabled them for inactivity. Add `commander` to `devDependencies` (or switch to `node:util` `parseArgs`) and re-enable `progressive-backfill.yml`, `chunk-recovery.yml`, and `update-pr-activity.yml`.
- **`node-fetch` is not a dependency** but is imported by the three `scripts/posthog/*.js` scripts. Use the global `fetch`.
- **`__dirname` one level too shallow** after scripts were moved into folders: `scripts/assets/convert-images.js`, `generate-pwa-icons.js`, `generate-pwa-screenshots.js`, `scripts/performance/performance-check.js`, `lighthouse-check.js`, `analyze-mobile-performance.js`. Each needs an extra `'..'`.

- `scripts/data-sync/backfill-reviews-comments.mjs` posts Inngest events to the serve endpoint (`/api/inngest`) instead of the event API, so non-dry-run mode is a no-op.
- `scripts/utilities/run-maintainer-eval.ts` imports `../src/evals`, which resolves to `scripts/src/evals` from its new folder; needs `../../src/evals`. All four `eval:*` npm scripts fail until fixed.
